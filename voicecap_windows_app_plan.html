상세 구현 로드맵 (4단계)

안정적인 Windows 데스크톱 앱 전환을 위한 단계별 작업 명세

1

내장 서버 SPA 서빙 및 fallback 라우팅 구현

server/index.js

Express 서버에 express.static(dist)를 마운트하고, API 및 웹소켓 경로가 아닌 모든 요청에 대해 dist/index.html을 반환하도록 설정합니다.

app.use(express.static(webDistPath));
app.get('*', (req, res) => res.sendFile(path.join(webDistPath, 'index.html')));
2

Electron 메인 윈도우 확장 및 네이티브 제어 고도화

desktop/comment-helper/main.cjs

기존 460x820 크기의 작은 헬퍼 창을 1440x900 크기의 메인 대시보드 창으로 전환하고, 마이크 권한 자동 승인, 트레이 최소화 핸들러를 추가합니다.

🎤 오디오/마이크 권한 핸들러

session.setPermissionRequestHandler로 브라우저 경고 팝업 없이 음성인식 마이크 즉시 연결

🛡️ 방송 보호 창 제어

창 닫기 이벤트(close) 인터셉트하여 트레이로 숨김(mainWindow.hide()) 처리

3

스테이징 스크립트 및 통합 패키징 환경 구성

stage-server.cjs & package.json

React 웹 산출물 dist/를 데스크톱 빌드 환경으로 자동 복사하도록 스테이징을 확장하고, 패키징 설정(electron-builder)을 'VoiceCAP' 브랜드로 갱신합니다.

"artifactName": "VoiceCAP-Setup.${ext}",
"productName": "VoiceCAP",
"shortcutName": "VoiceCAP"
4

패키징 빌드 및 E2E 실시간 기능 검증

통합 검증
1. 화면 및 라우팅

로그인 후 /live, /sales 이동 및 새로고침(F5) 시 404 없이 정상 렌더링

2. 하드웨어 출력

로컬 감열식 영수증 프린터(Xprinter) 무경고 자동 출력(silent) 확인

3. 오프라인 STT & 댓글

마이크 음성인식 감지 및 TikTok 실시간 댓글 스트림 수집 확인

원클릭 데스크톱 앱 빌드 명령어
