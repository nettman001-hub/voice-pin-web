결론: 일부 개선이 있지만 이 문구 그대로는 남은 오류가 있다.

채팅에서 제안한 지침을 글자 그대로 사용했다. 검토 대상의 실제 시각·원문을 붙이고 기존 18개 사례의 댓글·판매자 멘트 구간은 그대로 유지했다. 원본 selfHostedAdapter로 실제 모델을 호출했으며, 수집한 답을 원본 서버·클라이언트 후처리에 넣었다. 서버 DB는 메모리 대역이다. 제품의 프롬프트 생성 코드와 운영 DB·프린터는 변경·호출하지 않았다. HTTP 통신 외피는 API 규격의 JSON이며, AI에 전달한 지시와 답은 평문이다. JSON 출력 모드는 쓰지 않았다.

18개 사례 × 2회: 수행 36회, 실제 답변 36건, 기대대로 처리 27건, 오처리 9건, 응답 없음 0건. 보류 대상 오확정 7건, 정상 판매 오보류 2건, 다른 구매자·가격 확정 0건.

정상 판매: 18/20 · 보류 대상: 9/16 · 정확한 두 줄 형식 36/36 · 지정 형식과 정답을 모두 충족 22/36.

같은 모델의 기존 질문과 비교

기존 기본 ID 시험은 26회까지만 수행됐으므로 이번 36회와 겹치는 실행만 비교한다. 26개 대응 실행에서 기존 정답 18건 → 변경 정답 21건, 오확정 5건 → 3건. 양쪽 모두 답변을 받은 24개만 비교하면 18건 → 20건이다. 서로 다른 시점의 호출이므로 응답 시간 차이를 프롬프트만의 효과로 단정하지 않는다.
