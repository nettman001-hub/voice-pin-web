AUTOMATED RECONCILIATION & SMS

판매자가 손 하나 안 대는 입금·SMS 자동화

안드로이드 앱과 VoiceCAP 웹앱이 하나로 연동되어 정산부터 배송지 확보까지 자동 완성

은행 입금내역 자동 매칭 (Reconciliation)

통장 캡처 확인 불필요, 0.1초 입금완료 처리

1) 스마트폰 은행 푸시/SMS 실시간 감지

고객이 계좌로 송금하면, 스마트폰에 뜨는 은행 입금 알림(금액, 입금자명, 은행)을 안드로이드 백그라운드 리스너가 즉각 캡처하여 클라우드로 전송합니다.

2) VoiceCAP 웹앱 내 자동 대조 & 확정

웹앱의 정산 대사 엔진(`paymentMatching`)이 방송 주문 건의 청구 금액 및 고객 정보와 입금 내역을 자동 대조하여, 상태를 즉시 '입금완료(PAID)'로 전환합니다.

3) 입금자명 불일치 스마트 해결

닉네임 대신 본명으로 입금하거나 금액이 일치하는 건도 지능형 유사도 매칭으로 추천해주어 판매자가 버튼 한 번으로 승인 가능합니다.

양방향 SMS 수발신 완전 자동화

문자 발송부터 고객 주소 회신 파싱까지 원스톱

1) 고객별 정산서 SMS 원클릭 자동 발송

방송 종료 후 안드로이드 폰 통신망을 통해 고객들에게 "구매 상품 목록, 총 금액, 입금 계좌"가 포함된 정산 문자가 자동으로 전송됩니다. (유료 문자 API 비용 0원!)

2) 회신 문자에서 '배송지 주소' 자동 추출

고객이 "서울 강남구... 홍길동 010-..." 형태로 답장을 보내면, 스마트폰 앱이 이를 수신해 웹앱으로 전달하고 AI 파서가 이름, 연락처, 주소를 자동 추출해 배송 원장에 등록합니다.

3) 송장 출력 준비 완료 알림 자동화

주소 입력과 입금 확인이 모두 끝나면 웹앱에서 즉시 택배 송장을 뽑을 수 있도록 [발송대기] 카드로 자동 전환됩니다.
