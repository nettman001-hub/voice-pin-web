# VoiceCAP Windows 디자인 시안

`index.html`을 Windows의 Chrome 또는 Edge에서 열면 된다. 설치·npm·외부 네트워크가 필요 없다. HTML, CSS, JavaScript 세 파일을 같은 폴더에 둔다. SVG 상품 일러스트와 아이콘은 코드에 포함되어 있다. 외부 글꼴·이미지·CDN을 읽지 않는다.

이 시안은 **실제 앱이 아니라 샘플 데이터로 동선을 검토하는 로컬 프로토타입**이다. 서버 로그인, 음성 인식, 실제 방송 댓글, 결제, 인쇄, 고객 자료 저장을 수행하지 않는다. 새로고침하면 샘플 주문과 설정은 초기화된다.

## 조작 가능한 범위

| 위치 | 동작 |
|---|---|
| 왼쪽 메뉴 | 라이브·판매 내역·정산 전환, 보류 필터, 연결/설정 대화상자 |
| 라이브 댓글 | 검색, 구매자 선택, 선택 댓글의 샘플 수량 반영 |
| 판매 기록 | 단가·수량·메모 변경, 합계 계산, 가짜 확정/보류 |
| 최근 기록/판매 목록 | 상세 서랍, 수량·단가·상태·메모 변경 |
| 판매 내역 | 확정/보류 필터, 검색, 조건에 맞는 샘플 CSV 내보내기 |
| 정산 | 확정 주문 합계, 상품별 막대그래프, 일자/회차 표시, 확정 CSV |
| 기기 및 연결 | 연결 끊김/복구의 시각 상태 전환 |
| 음성 인식 토글 | 켜짐/정지 상태 표현, 실제 마이크 사용 없음 |
| 앱 설정 | 라이트/다크, 표준/컴팩트 |
| 알림 | 가짜 보류 건수 확인, 보류 목록 이동 |
| 상품·규칙·프로필·회차 | 구현할 기능과 현재 시안 범위를 설명하는 대화상자 |
| 저장 후 알림 | 마지막 샘플 생성/수정 되돌리기 |

`Ctrl+K`는 화면 이동, `Ctrl+1/2/3`은 라이브/판매/정산이다. 판매 작성 폼에 초점이 있을 때 `Ctrl+Enter`로 가짜 판매를 확정한다. `Escape`로 대화상자를 닫는다. 샘플 CSV만 브라우저의 다운로드 폴더에 저장될 수 있다.

실제 Windows 앱의 전체 화면·기능 계약은 상위 [화면 명세](../05_SCREEN_SPECIFICATIONS.md), [디자인 시스템](../04_UI_UX_DESIGN_SYSTEM.md), [전체 설계 안내](../README.md)를 따른다. 브라우저 시안 검수는 Windows 설치·OS 권한·STT·프린터·접근성 통합 검증을 대신하지 않는다.
