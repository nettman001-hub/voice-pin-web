# 구매요청 기반 판매 적용 상태

2026-09-30 배포 범위. [전체 목표 설계](./DESIGN.md)와 [전체 인수 명세](./ACCEPTANCE.md)는 이보다 넓다.

## 적용됨

- `저요`·`ㅈㅇ` 등의 구매 댓글을 원문과 계정 근거를 보존한 요청으로 기록한다. 문의·명시 철회·조건부 요청은 자동 확정에서 제외한다.
- 판매자의 `햇살언니께 드리겠습니다`, `네스트언니 챙겨드릴게요`, `이이돌언니께`, `뒷자리1234언니께` 같은 단건 배정 표현과 음성 가격을 연결한다. `1.5`와 `일점오`는 15,000원으로 변환한다.
- 유사 닉네임은 유일할 때만 선택하고, 숫자 식별자 충돌·동점 계정은 보류한다. 최근 댓글과 확정 발화를 STT 재연결 없이 즉시 대조한다.
- 판매 가격을 미리 등록하지 않아도 음성 가격으로 상품과 판매를 서버 트랜잭션에서 확정한다. 서버가 실제 댓글·계정·가격 발화·방송 상태를 다시 검증한다. 같은 operation의 재전송과 동일 요청 중복 배정은 차단한다.
- 서버 ACK 전에는 확정 매출·정산·배송·전표 출력에 넣지 않는다. 방송 홈에 구매요청, 확인 필요, 서버 저장 대기를 구분해 표시한다.
- 순수 함수 테스트와 운영 DB의 롤백형 합성 트랜잭션 테스트로 단건 확정·재전송·중복 방지·재구매를 검증한다.

## 아직 자동 처리하지 않음

- 복수 수량/옵션/묶음 가격, 상품 전환 경계가 불명확한 요청, 같은 발화 외의 선행 가격 안내는 확인 대상으로 남긴다.
- 규칙이 놓친 판매 멘트의 AI 누락 탐지와 AI 제안의 자동 배정은 연결되지 않았다. 기존 보류 AI 경로가 근거 없는 가격을 자동 반영하지 못하게 검증을 강화했고, 음성 판매의 AI 제안은 판매자 확인 대상으로 유지한다.
- 여러 구매자를 한 발화에서 동시에 배정, 복수 요청의 부분 배정·잔여 원장, 이미 확정된 판매의 취소·정정 원자성, 두 장치의 오디오 구간 중복 판정은 전체 설계의 후속 범위다.
- 실방송/STT 장치/프린터를 결합한 종단간 현장 검증은 수행하지 않았다. 따라서 전체 인수 명세의 완료를 주장하지 않는다.
