## 1. 앱 개요 및 핵심 아키텍처

VoiceCAP Android 앱은 라이브 방송 중 스마트폰을 통해 **실시간 댓글을 확인하고 터치 한 번으로 판매를 등록**하며, 고객 문의 문자를 PC 웹과 연동하는 통합 모바일 파트너 앱입니다.

```
┌─────────────────────────────────────────────────────────────┐
│                    VoiceCAP Android App                     │
├──────────────────────────────┬──────────────────────────────┤
│       🛍 판매관리 탭          │        💬 문자연동 탭         │
│   (ProductSalesView.java)    │    (SmsBridgeView.java)      │
├──────────────────────────────┼──────────────────────────────┤
│ • 실시간 방송 댓글 폴링 (1.5s) │ • 1회용 보안 기기 페어링     │
│ • 다중 댓글 1구매자 병합 선택 │ • 거래 고객 문자 필터링 동기화│
│ • 2초 타이머 전면 카메라 촬영 │ • 발송 대기 SMS 백그라운드 발송│
│ • 단가 변경 및 판매 소급 수정 │ • 15분 주기 JobScheduler 실행 │
│ • PC 프린터 전표 자동 출력 연동│                              │
└──────────────────────────────┴──────────────────────────────┘
                               │ HTTPS (X-VoiceCAP-Device-Token)
                               ▼
              VoiceCAP Edge Server (/sales-api)
                               │ Print Queue
                               ▼
                PC 댓글 도우미 / 영수증 프린터
```

### 주요 아키텍처 특징
- **완전한 권한 격리**: 판매관리 탭은 카메라 권한(`CAMERA`) 외에 SMS 권한을 요구하지 않으며, 문자연동 설정을 완료하지 않아도 독립적으로 정상 작동합니다.
- **멱등성(Idempotency) 보장**: 모든 판매 등록, 상품 변경, 신원 확인 요청은 클라이언트에서 생성한 고유 `operationId`(UUID)를 동반하여 네트워크 재시도 시에도 중복 결제나 중복 상품 등록이 발생하지 않습니다.
- **낙관적 락(Optimistic Concurrency Control)**: 회차(`sessionRevision`), 상품(`productRevision`), 판매(`salesRevision`)의 버전을 엄격히 검증하여 PC 웹 또는 다른 기기에서의 변경과 충돌 시 데이터 오염을 방지합니다.

## 2. 상단 탭 내비게이션

앱 화면 상단에 2개의 탭 전환 버튼이 상시 노출됩니다.

- **`🛍 판매관리` 버튼**: 방송 중 실시간 상품 등록, 댓글 확인, 판매 확정, 판매 수정을 진행하는 메인 작업 화면입니다.
- **`💬 문자연동` 버튼**: 최초 기기 연결, SMS 기본 앱 권한 설정, 문자 수발신 동기화 상태를 관리하는 화면입니다.
- **생명주기 및 상태 보존**: 화면 회전이나 탭 이동 시에도 현재 선택된 구매자 목록, 입력 폼 내용이 그대로 유지되며, 백그라운드 전환 시 불필요한 네트워크 폴링을 자동으로 중단(`stop()`)하여 배터리와 데이터를 절약합니다.

## 3. 탭 1: 🛍 라이브 판매관리

### 3.1 헤더 및 활성 회차 정보
- **방송 회차 표시**: 현재 진행 중인 라이브 세션의 표시 코드(예: `2026-09-08 라이브 (v3)`)가 표시됩니다.
- **`[설정]` 버튼**: 판매 정책 설정 다이얼로그(`SalesSettingsDialog`)를 호출합니다.
- **`[+ 상품등록]` 버튼**: 신규 상품 등록 다이얼로그(`ProductRegistrationDialog`)를 호출합니다. (판매 설정에서 상품등록이 허용된 경우에만 노출)

### 3.2 현재 판매상품 및 회차 요약 카드
- **이번 회차 판매 통계**: 이번 라이브 방송에서 판매된 총 수량과 누적 금액을 실시간 표시합니다 (예: `이번 회차: 42개 · ₩1,250,000`).
- **현재 활성 상품 정보**: 방송 중 현재 판매 대상 상품의 코드, 상품명, 단가 및 이미지 형태를 안내합니다.
  - 예: `현재 상품: 0007 · 캐시미어 니트 (₩35,000) [사진]`
  - 가격이 아직 입력되지 않은 경우 `(가격 미지정)`으로 표시되며 판매 확정이 차단됩니다.
- **프린터 상태 배지**: 지정된 라벨/영수증 프린터의 온라인/오프라인 연결 상태를 표시합니다 (예: `프린터: 카운터 롤프린터 (온라인)`).
- **`[수정]` 버튼**: 이미 판매된 내역을 열람하고 단가 소급 변경 및 구매자 수량을 조정하는 `ProductChangeDialog`를 엽니다.

### 3.3 실시간 댓글 피드 및 구매자 선택
화면 중앙에는 1.5초 간격으로 서버로부터 수신되는 실시간 방송 댓글 목록이 표시됩니다.

| 표시 항목 | 상세 설명 |
| :--- | :--- |
| **선택 체크박스** | 해당 댓글/구매자가 현재 판매 대상으로 선택되었는지를 나타냅니다. |
| **닉네임 및 댓글 내용** | 고객의 플랫폼 닉네임과 실시간 댓글 텍스트가 표시됩니다. |
| **구매자 누적 통계** | 구매자 정보가 확인된 경우, `회차 N개 (₩금액) · 누적 M회 (₩금액)` 통계가 행 하단에 함께 노출되어 충성 고객 여부를 즉시 파악할 수 있습니다. |
| **수량 조절기 (`-` / `+`)** | 댓글을 선택하여 구매자가 지정되면 나타납니다. 기본값은 1개이며 판매자가 터치하여 수량을 늘리거나 줄일 수 있습니다. |

#### 💡 다중 댓글 합산 및 선택 규칙
1. **동일 구매자 자동 합산**: 동일한 고객이 "저요", "1번 구매합니다", "하나 더 주세요" 등 댓글을 여러 개 남겨 모두 터치하더라도, **구매자 1명으로 통합**되며 기본 수량은 **1개**로 안전하게 유지됩니다 (수량은 판매자가 `+` 버튼으로 직접 변경).
2. **선택 해제 규칙**: 동일 고객의 댓글 중 일부를 체크 해제하더라도 다른 댓글이 선택되어 있다면 구매자 상태와 조정된 수량이 유지됩니다. 해당 고객의 **마지막 선택 댓글을 해제할 때만** 선택 목록에서 완전히 제거됩니다.

### 3.4 구매자 신원 확인 (동명이인 병합 방지)
댓글의 `buyerId`가 서버에 아직 등록되지 않은 첫 방문 고객 댓글을 터치하면 **구매자 신원 확인 팝업(`BuyerConfirmDialog`)**이 자동으로 실행됩니다.

1. **후보 자동 검색**: 댓글 닉네임과 일치하는 기존 고객 목록을 서버에서 자동 검색합니다.
2. **동명이인 방지 확인**:
   - **기존 고객 연결**: 검색 목록에 동일 고객이 나타나면 `[선택]`을 눌러 해당 고객의 기존 구매 이력과 안전하게 연결합니다.
   - **신규 고객 확인**: 기존 고객과 다른 새로운 고객인 경우 `[신규 구매자로 수동 확인 (MANUAL_CONFIRMED)]`을 눌러 새 고객 식별자를 즉시 발급받아 연결합니다.
3. **결과**: 확인이 완료되면 해당 고객의 댓글이 선택 상태로 전환되며 수량 조절 버튼이 활성화됩니다.

### 3.5 하단 고정 액션바 및 판매 확정
화면 하단에 어두운 배경의 액션바가 고정되어 있습니다.

- **실시간 선택 집계**: `선택 3명 (총 4개) · ₩140,000`과 같이 현재 선택된 인원, 총 수량, 예상 판매 총액이 실시간 계산됩니다.
- **`[판매등록완료]` 버튼**:
  - 선택된 구매자가 1명 이상이고 단가가 설정되어 있을 때 활성화됩니다.
  - 버튼 클릭 시 현재 활성 상품과 회차 버전을 고정하여 서버로 일괄 판매 등록(`commit-sales`)을 요청합니다.
  - 등록 성공 시 선택 목록이 자동으로 초기화되고 회차 통계가 갱신되며, 토스트 메시지를 통해 **각 구매자별 인쇄 전표 접수 상태**가 표시됩니다.

### 3.6 신규 상품등록 (2초 카운트다운 카메라)
우측 상단의 `[+ 상품등록]` 버튼을 누르면 새 상품을 즉시 준비하고 활성화할 수 있습니다.

```
[상품코드/명 입력] ──> [prepare-product] ──> [2초 카운트다운] ──> [commit-product]
(예: 0007, 35000원)      (서버 초안 발급)        (카메라 촬영/대체)     (상품 활성화 완료)
```

1. **상품코드 및 명칭 입력**:
   - 숫자만 입력한 경우(예: `0007`) **선행 0을 문자열로 그대로 보존**하여 등록합니다.
   - 텍스트 입력 시 상품명으로 등록되며 관리 코드는 서버가 중복 없이 자동 발급합니다.
2. **판매단가 입력**: 즉시 판매를 위해 단가를 입력합니다 (추후 수정 가능).
3. **2초 카운트다운 촬영**:
   - 카메라 설정이 켜져 있는 경우, 등록을 누르면 2초 카운트다운 안내창이 표시된 후 자동으로 상품 사진을 촬영합니다.
   - **촬영 건너뛰기**: 촬영 대신 번호판을 사용하고자 할 경우 `[촬영 건너뛰고 번호이미지로 등록]` 버튼을 누르면 서버가 생성하는 번호 이미지로 즉시 대체 등록됩니다.
4. **등록 완료**: 상품이 저장되는 즉시 현재 활성 상품 카드가 새 상품으로 교체되어 댓글 판매를 즉시 시작할 수 있습니다.

### 3.7 상품별 판매내역 수정 및 단가 소급적용
방송 중 상품의 판매단가를 잘못 입력했거나, 주문 취소/수량 변경이 발생한 경우 카드 우측의 `[수정]` 버튼을 눌러 `ProductChangeDialog`를 실행합니다.

```
  ┌─────────────────────────────────────────────────────────┐
  │                 상품별 판매내역 및 수정                 │
  ├─────────────────────────────────────────────────────────┤
  │ [수정할 상품 선택: 0007 - 캐시미어 니트 (₩35,000) ▼]      │
  │                                                         │
  │ 상품명: [캐시미어 니트                                ] │
  │ 판매단가(원): [30000                                  ] │
  │ ⚠️ 단가 변경 시 기존 판매 전체에 소급 적용됩니다.      │
  ├─────────────────────────────────────────────────────────┤
  │ 구매자 목록                       [+ 구매자 추가]       │
  │ • 홍길동: 수량 [-] 2 [+]개 · 기존 ₩70,000   [제외]      │
  │ • 이영희: 수량 [-] 1 [+]개 · 기존 ₩35,000   [제외]      │
  ├─────────────────────────────────────────────────────────┤
  │ [변경 미리보기]                     [변경 적용]         │
  └─────────────────────────────────────────────────────────┘
```

1. **상품 선택**: 드롭다운 메뉴를 통해 이번 회차에서 판매된 모든 상품을 선택할 수 있습니다.
2. **단가 변경 (소급 적용)**:
   - 판매단가를 변경(예: 35,000원 → 30,000원)하면 **해당 상품으로 이미 등록된 모든 기존 구매자의 주문 금액이 함께 재계산**됩니다.
3. **구매자 주문 조정**:
   - 각 구매자의 수량을 `+` / `-` 버튼으로 직접 증감할 수 있습니다.
   - `[제외]` 버튼을 누르면 취소 처리되며, 다시 `[복구]`할 수 있습니다.
   - `[+ 구매자 추가]` 버튼으로 누락된 구매자를 수동 검색하여 추가할 수 있습니다.
4. **2단계 안전 검증 (미리보기 필수)**:
   - `[변경 미리보기]` 버튼을 클릭하면 서버가 변경 전후 단가, 회차 총액 증감, 영향받는 구매자별 차액 목록을 산출하여 화면에 표시합니다.
   - 미리보기를 확인한 후에만 `[변경 적용]` 버튼이 활성화되어 실수를 미연에 방지합니다.
5. **정정 전표 자동 발행**: 변경이 확정되면 PC 도우미 프린터로 **`정정 전표(CORRECTION)`**가 자동 발행되어 포장 담당자가 수정 사항을 즉시 확인할 수 있습니다.

### 3.8 판매 설정
헤더의 `[설정]` 버튼을 누르면 3가지 핵심 운영 정책을 토글할 수 있습니다.

- **상품등록 기능 허용**: 방송 중 모바일에서 새 상품을 등록할 수 있도록 허용합니다. (체크 해제 시 상단 [+ 상품등록] 버튼 숨김)
- **상품사진 촬영 및 등록 허용**: 카메라 촬영 모드를 활성화합니다. (체크 해제 시 카메라 권한을 요청하지 않고 자동으로 번호이미지 모드로 동작)
- **상품명 / 번호 수동 입력 허용**: 판매자가 상품 번호나 이름을 직접 타이핑할 수 있게 합니다. (체크 해제 시 자동 발급 번호 모드로 고정)

## 4. 탭 2: 💬 문자연동 (SMS Bridge)

`💬 문자연동` 탭은 웹 대시보드와 고객 휴대폰 간의 SMS/MMS를 안전하게 중계하는 백그라운드 브리지 기능을 제공합니다.

### 4.1 1회용 연결 코드로 기기 페어링
1. PC 웹 브라우저에서 `voicecap.shop` 로그인 후 **마이페이지 & 백업 → voicecapSMS 휴대폰 연결**로 이동합니다.
2. **[휴대폰 연결 코드 만들기]**를 클릭하여 발급된 **10자리 1회용 코드**를 확인합니다 (10분 유효).
3. Android 앱의 `기기 연결 코드` 입력창에 코드를 입력하고 **[이 휴대폰 연결]**을 누릅니다.
4. 성공 시 서버로부터 보안 기기 토큰(`X-VoiceCAP-Device-Token`)을 발급받아 암호화 저장소에 안전하게 보관됩니다.

### 4.2 기본 SMS 앱 및 권한 설정
1. **[기본 SMS 앱 · 권한 설정]** 버튼을 클릭합니다.
2. 개인정보 전송 안내 팝업 내용을 확인하고 **[동의함]**을 누릅니다.
3. Android 시스템 대화상자에서 VoiceCAP을 **기본 SMS 앱**으로 승인합니다.
4. 문자 읽기, 수신, 발신 권한을 모두 허용하면 `연동 준비 완료` 녹색 상태가 표시됩니다.

### 4.3 실시간/주기적 문자 동기화 및 개인정보 보호
- **스마트 개인정보 필터링**: 모든 개인 문자를 전송하지 않으며, **주문/입금/배송 관련 고객 거래 문의** 및 판매자가 먼저 보낸 발신 번호에 대해서만 동기화합니다 (은행 알림, 인증번호 OTP, 사적인 문자는 스마트폰 내부에서 원천 차단).
- **자동 백그라운드 동기화**: Android `JobScheduler`를 통해 15분 주기로 백그라운드에서 예약된 SMS/MMS 발송 큐를 확인하여 자동으로 고객에게 문자를 발송합니다.
- **수동 동기화**: **[지금 동기화 및 발송 처리]** 버튼을 터치하여 언제든지 즉시 수발신 동기화를 강제 실행할 수 있습니다.
- **안전한 연결 해제**: **[이 휴대폰 연결 해제]**를 누르면 저장된 토큰이 즉시 무효화되고 서버와의 모든 데이터 통신이 영구 중단됩니다.

## 5. 영수증/라벨 프린터 출력 상태 안내

판매 등록(`commit-sales`) 또는 상품 변경(`commit-product-change`) 완료 시, PC 도우미와 연결된 영수증/라벨 프린터의 작업 상태가 실시간으로 반환되어 토스트 및 팝업에 표시됩니다.

| 상태 코드 | 앱 내 표시명 | 상태 설명 및 대응 방법 |
| :--- | :--- | :--- |
| `QUEUED` | **출력 대기** | 서버 인쇄 대기열에 정상 접수되었으며 PC 도우미의 수신을 기다리는 상태입니다. |
| `CLAIMED` | **처리 준비** | PC 도우미가 인쇄 작업을 인출하여 프린터 전송을 준비 중입니다. |
| `SUBMITTING`| **접수 중** | PC 도우미에서 Windows 인쇄 스풀러로 명령을 전달 중입니다. |
| `SUBMITTED` | **Windows 인쇄 접수** | 영수증 프린터로 인쇄 데이터가 성공적으로 전달되었습니다. |
| `FAILED` | **실패** | 프린터 전원 꺼짐, 용지 부족 등으로 인쇄가 실패했습니다. (판매 데이터는 정상 저장되어 있으므로 다시 판매등록하지 마세요) |
| `UNKNOWN` | **출력 여부 확인 필요** | PC 도우미 응답 타임아웃 등으로 최종 출력 여부를 수동 확인해야 합니다. |

> [!IMPORTANT]
> 인쇄 상태가 `FAILED`나 `UNKNOWN`이더라도 **서버 상의 판매 데이터는 이미 정상 저장**되었습니다. 동일 판매를 앱에서 다시 누르면 중복 판매가 발생하므로, PC 도우미나 웹 대시보드에서 재인쇄를 진행하세요.

## 6. 서버 연동 오류 코드 및 문제 해결

| HTTP 코드 | 서버 에러 코드 | 원인 및 해결 방법 |
| :--- | :--- | :--- |
| `401` | `AUTH_REQUIRED` / `DEVICE_REVOKED` | 기기 토큰이 만료되었거나 웹에서 연결이 해제되었습니다. `💬 문자연동` 탭에서 기기 연결 코드를 다시 발급받아 재페어링하세요. |
| `403` | `CAPABILITY_DENIED` | 현재 기기에 판매 권한이 부여되지 않았습니다. PC 웹 관리자의 **기기 관리** 메뉴에서 해당 스마트폰의 `판매 권한`을 켜주세요. |
| `409` | `REVISION_CONFLICT` / `ACTIVE_PRODUCT_CHANGED` | PC 웹이나 다른 기기에서 상품/회차 정보가 먼저 변경되었습니다. 입력값이 보존된 상태로 최신 정보를 자동 갱신하므로 확인 후 다시 등록하세요. |
| `409` | `PRODUCT_CODE_EXISTS` | 이미 동일한 상품 코드가 이번 회차에 등록되어 있습니다. 다른 번호를 입력하세요. |
| `410` | `PREVIEW_EXPIRED` / `DRAFT_EXPIRED` | 변경 미리보기 토큰(유효시간 5분)이 만료되었습니다. `[변경 미리보기]` 버튼을 다시 누른 후 적용하세요. |
| `422` | `PRICE_REQUIRED` | 상품의 판매 단가가 0원이거나 설정되지 않았습니다. 단가를 먼저 입력한 뒤 판매등록을 진행하세요. |
| `422` | `BUYER_UNRESOLVED` | 신원이 확인되지 않은 구매자가 포함되어 있습니다. 해당 댓글을 터치하여 신원 확인 팝업에서 확인을 완료하세요. |
| `503` | `TEMPORARILY_UNAVAILABLE` | 일시적인 네트워크 순단입니다. 앱이 기존 `operationId`를 보존하고 있으므로 안심하고 다시 시도하세요. |
